# Динамічні дозволи superadmin

Після накладання штатних патчів на копію стендового frontend застосуйте `superadmin-rbac.patch` до кореня цієї копії. Скопіюйте `test_superadmin_rbac.py` до `auth/web_hmi/` та запустіть `web_hmi.test_superadmin_rbac` і `web_hmi.test_access` від непривілейованого користувача з `PYTHONPATH`, що містить корінь копії та її каталог `auth`.

Для основного HMI застосуйте той самий патч до копії чинного релізу, перевірте чинний набір тестів доступу та розгорніть її окремим погодженим перемиканням лише HMI. Патч використовує реєстр дозволів цільового релізу. Схема БД і призначення ролей не змінюються. Після перезапуску перевірте `GET /api/session` для superadmin і для користувача нижчої ролі. Для відкату поверніть попереднє дерево HMI та перезапустіть лише HMI.

На стендовому етапі залишайте Web ARM, Web DISARM і BENCH_RELEASE вимкненими. Наявність `stop.reset` у сесії не змінює стан STOP або фізичних блокувань.
