# UGV public source snapshot

This branch contains a single source snapshot without the private repository history. It includes ArUco processing and relative maps, mission planning, the candidate Pixhawk owner and ExternalNav transport, the HMI and IPC source, and BrakeLink with its existing safety gates.

Device identifiers, local addresses, host-specific account names and session IDs are examples. Embedded test credentials are synthetic fixtures. Source maps use relative coordinates. Deployment scripts and live service configuration, device calibration binaries, parameter dumps, telemetry, archived disk images and historical deployment copies were excluded. Supply site-specific configuration and calibration from a private, reviewed source before deployment. This snapshot does not grant traction or enable an operational AUTO run.
